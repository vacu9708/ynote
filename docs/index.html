Ynote: sticky notes for Linux, made for engineers

Commands, code, tables, and checklists in small notes beside your editor, edited as in Confluence and copied out as Markdown. Free and open source.

Download the .deb View on GitHub
  • Everything a note needsCode blocks you copy one command at a time (double-click its line), tables whose cells hold lists and code, expands that fold away, checklists, headings, links, emoji, and pasted images.
  • Type / to insert anythingOr Markdown such as **bold** and - ; Ctrl+. finds an emoji by name, and F1 lists every key.
  • Find in every noteHidden ones too, plain or as a regular expression: hidden notes stay out of the way and work as runbooks.
  • Markdown in and outCopy to other apps as Markdown, and code alone as it is, ready for a terminal. Pasted Markdown keeps its formats.
  • Colors and always on topSeven colors, see-through down to the title bar; pin a note on top, or collapse it to its title bar.
  • Arrange from the keyboardSnap notes into half-screen columns with Alt and the arrows, and step through them with Alt and the wheel.
  • Local and privateNotes save as you type, in ~/.config/ynote/. Nothing is uploaded.

Install

Ynote runs on Ubuntu 22.04 and later and other Debian-based Linux desktops, on X11 and Wayland. Download ynote_<version>.deb from the latest release, then install it from the download folder. apt also installs what Ynote needs.

sudo apt install ./ynote_*.deb

Open Ynote from the app grid, or run ynote. It starts at login from then on. Notes from Ynote 1.x open as they were, and their old file is kept as ~/.config/ynote/notes-old.json.
