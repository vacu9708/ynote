Ynote: sticky notes for Linux, made for engineers

Keep commands, code snippets, debugging context, screenshots, and to-dos in small floating notes beside your editor. Free and open source.

Download the .deb View on GitHub

Features

  • Always-on-top notesFloating windows that save automatically and can be pinned above other windows.
  • Code blocksCopy one command at a time: double-click a line to select just that command.
  • Checklists and formattingChecklists, bullet lists, bold text, headings, dividers, links, emoji, and inline code for paths and names.
  • ImagesPaste a screenshot into a note with Ctrl+V.
  • Searchable hidden notesHide notes you don't need on screen. The All notes search still finds them, so they work as runbooks and cheat sheets.
  • Colors, opacity, collapsingSeven note colors, adjustable background opacity, and collapsing a note to its title bar.
  • Snapping and switchingSnap notes into half-screen columns with Alt and the arrow keys, and step through your notes with Alt and the mouse wheel.
  • Local and privateNotes are saved as plain files in ~/.config/ynote/. Nothing is uploaded.

Install

Ynote runs on Debian- and Ubuntu-based Linux desktops with GTK 3 and Python 3.10 or later, including Wayland sessions. Download ynote_<version>.deb from the latest release, then install it from the download folder. apt also installs what Ynote needs.

sudo apt install ./ynote_*.deb

Open Ynote from the app grid, or run ynote.
